# AGENTS

Ты работаешь только в проекте `serpukhov-2026-trip` — отдельном публичном сайте короткого семейного маршрута Москва → Серпухов → Москва.

## Hard Rules

- Не добавлять точный домашний адрес: публичная стартовая точка — только район Солнцево.
- Не публиковать телефоны, фамилии, данные бронирований, номера автомобиля и другие приватные данные.
- Не смешивать этот маршрут с проектом `bali-2026-trip` или бизнес-репозиториями.
- Не выдавать непроверенное расписание за подтверждённое.

## Source Of Truth

`src/data/trip.json` — единый источник карты, тайминга, альтернатив, проживания и ссылок.

Если меняется маршрут, одновременно проверить:

- порядок точек и линии карты;
- тайминг обоих дней;
- часы работы;
- статус обязательной/optional точки;
- логику ночёвки и возврата к 17:00.

## Workflow

1. Проверить `git status`.
2. Читать `README.md`, `PROJECT_SPEC.md`, `TASKS.md`, `UX.md`.
3. Перед контентными изменениями читать `src/data/trip.json`.
4. После изменений запускать `npm run build`.
5. Просматривать всю страницу на desktop и mobile, проверять карту, фильтры и ссылки.
6. Перед commit проверить diff, `.gitignore`, secrets и временные артефакты.
