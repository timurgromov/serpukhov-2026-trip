# Serpukhov 2026 Trip

Публичная карта поездки из Солнцево в Серпухов на 28–29 июля 2026 года.

Плановый URL:

```text
https://timurgromov.github.io/serpukhov-2026-trip/
```

## Стек

- Astro
- TypeScript
- Leaflet + OpenStreetMap
- GitHub Pages
- единый источник маршрута: `src/data/trip.json`

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Правила

- На публичной карте используется только район Солнцево, без домашнего адреса.
- Линии карты показывают последовательность точек, а не точную автомобильную трассу.
- Расписания с пометкой «подтвердить» нужно повторно проверить перед поездкой.
- Маршрут, карта и список решений редактируются через `src/data/trip.json`.
